# Team Desk for Windows

Tasks, time tracking and a self-writing daily journal for small office teams.
Details, screenshots and setup steps: **https://aashik.xyz/team-desk/**

This repository only hosts the installers. Download them from [Releases](https://github.com/aashikelahe/team-desk-releases/releases/latest).

- **TeamDesk-Setup-x.y.z.exe**: full installer for a new PC (Windows 10/11, no admin rights needed).
- **TeamDesk-Update-x.y.z.zip**: small update for PCs that already have Team Desk. Extract it and run `Install-Update.bat`. Update the server PC first.
